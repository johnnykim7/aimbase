Aimbase Chat Widget 샘플

이 페이지는 @aimbase/chat-widget-embed 를 실제 소비앱에서 어떻게 사용하는지 보여주는 E2E 샘플입니다. 아래 각 섹션은 동일한 Web Component 를 display 모드만 달리 한 결과입니다.

  • inline: 이 페이지 내 고정 컨테이너
  • bubble: 우하단 말풍선 (클릭 시 플로팅 패널)
  • panel: 측면 사이드 패널 (JS 로 토글 가능)

브라우저 → 소비앱 BFF (localhost:3999/my-bff/aimbase-token) → Aimbase (localhost:8181) 3-Tier 로 동작합니다.

① Inline 모드

아래는 <aimbase-chat display="inline"> 한 줄로 채팅을 삽입한 결과입니다.

② 워크플로우 실행 구독

실행 중인 run ID 를 입력하면 위젯이 workflow.snapshot / step / done SSE 를 수신해 진행을 실시간 표시합니다 (종료된 run 도 snapshot 1회 + done 후 close).

③ 파일 첨부 데모 (CR-061)

위의 inline 위젯에서 입력창 좌측의 📎 아이콘을 클릭하거나, 이미지/PDF 파일을 위젯 위로 드래그앤드롭하면 첨부됩니다.

  • 지원 MIME: PNG / JPEG / GIF / WEBP / PDF
  • 크기 제한: 이미지 10MB, PDF 32MB (세션당 최대 10개)
  • Claude 계열 모델은 PDF 를 네이티브 해석, 그 외는 텍스트 추출 폴백
  • 첨부는 현재 메시지 1회에만 컨텍스트로 사용되고 세션 종료 시 자동 정리됩니다

④ Bubble 모드

아래 엘리먼트는 페이지 우하단에 버블 버튼으로 떠 있습니다. 클릭하면 플로팅 채팅 패널이 열립니다.
