Aimbase Chat Widget — 소비앱 통합 가이드 v1

이 페이지는 Aimbase 서버가 인증 없이 공개 서빙합니다. 소비앱은 아래 리소스를 CDN 처럼 직접 참조하거나 curl -O 로 다운받아 자체 호스팅할 수 있습니다.

목차
  • 빌드 산출물 (공개 URL)
  • 전체 플로우
  • 관리자 세팅 (1회)
  • BFF 구현 (백엔드)
  • 브라우저 삽입 (프론트엔드)
  • UI 모드 선택
  • 트러블슈팅

빌드 산출물 (공개 URL)

URL용도크기
/widget/v1/aimbase-chat.umd.global.js <script> 로드용 (전역 window.AimbaseChat)~17 KB
/widget/v1/aimbase-chat.esm.js 번들러 import (Vite/webpack 등)~25 KB
/widget/v1/aimbase-chat.d.ts TypeScript 타입 정의~4 KB
/widget/v1/sample-bff/server.js Node 샘플 BFF (외부 의존 0)코드 ~100줄

인증 없이 접근 가능. 장기 캐시(30일) 적용되며, 번들이 업데이트되면 ETag/Last-Modified 로 자동 재검증됩니다.

전체 플로우

소비앱 브라우저           소비앱 BFF              Aimbase 서버
(oms.com)              (API Key 보관 유일)      (aimbase.com)

<aimbase-chat>  ──▶   /my-bff/aimbase-token ──▶  /api/v1/sessions/
 authResolver()                                   issue-widget-token
                ◀──   (30분 JWT)           ◀──   (type=widget JWT)

브라우저가 받은 JWT 로 직접 호출:
  /chat/completions (SSE)
  /workflows/runs/{id}/subscribe (SSE)
  /knowledge-sources/.../chunks/...

핵심 원칙: Aimbase API Key 를 브라우저에 절대 내려보내지 않는다. BFF 가 서버간 호출로 단기 JWT 를 대리 발급받아 브라우저에 전달하는 3-Tier 구조만 안전.

관리자 세팅 (Aimbase 운영자가 1회 수행)

1. 소비앱 전용 API Key 발급

curl -X POST "$AIMBASE/api/v1/platform/api-keys" \
  -H "Authorization: Bearer $SUPER_ADMIN_JWT" \
  -H "Content-Type: application/json" \
  -d '{"name":"OMS 위젯 BFF 키","domainApp":"oms","tenantId":"rescue_prod"}'
# 응답의 apiKey 값은 1회만 조회 가능. BFF env 로 안전 전달.

2. 소비앱 Origin 을 화이트리스트에 추가

UPDATE global_config
   SET config_value='https://oms.company.com,https://rescue.company.com',
       updated_by='ops', updated_at=NOW()
 WHERE config_key='widget.allowed-origins';

CSV 로 여러 origin. 프로토콜+도메인+포트 정확 일치 필요. * 불가.

키기본설명

BFF 구현 (소비앱 백엔드 개발자)

BFF 의 유일한 역할은 API Key 를 env 에 보관하고 토큰 요청을 Aimbase 로 중계하는 것. 앞에 소비앱 자체 로그인 검증을 둔다.

Node.js

const http = require("http");

async function issueWidgetToken() {
  const res = await fetch(`${process.env.AIMBASE_URL}/api/v1/sessions/issue-widget-token`, {
    method: "POST",
    headers: {
      "X-API-Key": process.env.AIMBASE_API_KEY,
      "X-Tenant-Id": process.env.AIMBASE_TENANT_ID,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      origin: process.env.ALLOWED_ORIGIN,
      scopes: ["chat:stream", "workflow:subscribe", "rag:read"],
      ttl_seconds: 1800,
    }),
  });
  if (!res.ok) throw new Error(`Aimbase token ${res.status}`);
  return (await res.json()).data;
}

http.createServer(async (req, res) => {
  if (req.method === "POST" && req.url === "/my-bff/aimbase-token") {
    // TODO: 자체 사용자 세션 검증
    const token = await issueWidgetToken();
    res.writeHead(200, { "Content-Type": "application/json" });
    res.end(JSON.stringify(token));
  }
}).listen(3000);

Spring Boot (Java)

@RestController
public class AimbaseTokenController {
  @Value("${aimbase.url}")       private String aimbaseUrl;
  @Value("${aimbase.api-key}")   private String apiKey;
  @Value("${aimbase.tenant-id}") private String tenantId;
  @Value("${widget.origin}")     private String origin;

  private final RestClient rest = RestClient.create();

  @PostMapping("/my-bff/aimbase-token")
  public Map<String, Object> issue() {
    var body = Map.of(
      "origin", origin,
      "scopes", List.of("chat:stream","workflow:subscribe","rag:read"),
      "ttl_seconds", 1800
    );
    Map<String, Object> wrap = rest.post()
        .uri(aimbaseUrl + "/api/v1/sessions/issue-widget-token")
        .header("X-API-Key", apiKey)
        .header("X-Tenant-Id", tenantId)
        .body(body).retrieve().body(Map.class);
    return (Map<String, Object>) wrap.get("data");
  }
}

FastAPI (Python)

import os, httpx
from fastapi import APIRouter
router = APIRouter()

@router.post("/my-bff/aimbase-token")
async def issue_token():
    async with httpx.AsyncClient() as c:
        r = await c.post(
            f"{os.environ['AIMBASE_URL']}/api/v1/sessions/issue-widget-token",
            headers={"X-API-Key": os.environ["AIMBASE_API_KEY"],
                     "X-Tenant-Id": os.environ["AIMBASE_TENANT_ID"]},
            json={"origin": os.environ["ALLOWED_ORIGIN"],
                  "scopes": ["chat:stream","workflow:subscribe","rag:read"],
                  "ttl_seconds": 1800},
        )
    r.raise_for_status()
    return r.json()["data"]

체크리스트

  • API Key 는 환경변수에만. 코드·로그·번들 금지.
  • BFF 호출 앞에 자체 사용자 인증 검증.
  • origin 은 BFF 가 고정값으로 주입하거나 검증.

브라우저 삽입 (소비앱 프론트엔드 개발자)

A. CDN 방식 (Aimbase 가 서빙)

<script src="https://aimbase.company.com/widget/v1/aimbase-chat.umd.global.js"></script>
<aimbase-chat
  base-url="https://aimbase.company.com"
  token-endpoint="/my-bff/aimbase-token"
  display="bubble"></aimbase-chat>

B. 다운로드 방식 (소비앱 자체 호스팅)

# 소비앱 배포 스크립트에 1회
curl -O https://aimbase.company.com/widget/v1/aimbase-chat.umd.global.js
mv aimbase-chat.umd.global.js public/assets/
<script src="/assets/aimbase-chat.umd.global.js"></script>
<aimbase-chat base-url="https://aimbase.company.com"
              token-endpoint="/my-bff/aimbase-token"
              display="bubble"></aimbase-chat>

C. npm 방식 (번들러 통합)

import { defineAimbaseChat, createWidget } from "@aimbase/chat-widget-embed";

// Web Component 로
defineAimbaseChat();

// JS API 로 직접 (React/Vue 컨테이너)
const handle = createWidget({
  baseUrl: "https://aimbase.company.com",
  authResolver: async () => (await (await fetch("/my-bff/aimbase-token", { method: "POST" })).json()),
  display: "inline",
  target: document.getElementById("chat-container"),
  ragSourceId: "kb_rescue",
  contextProvider: () => ({ orderId: currentOrderId, page: "order-detail" }),
  on: {
    onWorkflowStep: (ev) => console.log("workflow", ev),
    onApprovalRequired: (ev) => openMyOwnApprovalFlow(ev),
  },
});

트러블슈팅

증상해결
CORS 에러 (프리플라이트 차단)widget.allowed-origins 에 소비앱 origin 추가 (프로토콜·포트 정확히)
401 "API Key is required"BFF 가 JWT 로 호출 중. 반드시 X-API-Key 헤더
400 "origin is not allowed"토큰 발급 body 의 origin 과 화이트리스트 불일치
403 간헐 발생토큰 만료. on.onTokenExpiring 에서 재시도
citations 없음rag-source-id 미지정 또는 해당 소스 검색 결과 0건
SSE 연결 후 이벤트 없음이미 종료된 run (snapshot + done 1회씩 오고 close, 정상)
