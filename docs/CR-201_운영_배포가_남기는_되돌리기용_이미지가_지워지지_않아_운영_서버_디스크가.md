## 2. 원인

| 순번 | 자리 | 지금 동작 | 근거 |
|---|---|---|---|
| 1 | chaws 배포 | api, 실행기, 음성 생성기를 올릴 때마다 `<이미지>:latest` 에 `pre-<시각>` 태그를 더한다 | `deploy.sh` `chaws_keep_image` |
| 2 | wjbid 배포 | 같은 모양 | `deploy.sh` `wjbid_keep_image` |

59 개발기 배포는 pre- 태그를 붙이지 않아 이 건과 상관없다.

## 3. 바꾼 것

### 3.1 정리 스크립트 `scripts/prune-pre-images.sh`

서버에서 `bash -s` 로 돈다. 인자는 `[--dry-run] <남길 개수> <이미지> ...`.

- 넘겨받은 이미지의 `pre-YYYYMMDD-HHMMSS` 태그를 최근 것부터 세어 남길 개수까지 두고 나머지를 `docker rmi` 한다. `-f` 는 쓰지 않는다
- 컨테이너(멈춘 것 포함)가 쓰는 이미지의 태그는 남긴다
- 사람이 붙인 다른 형식의 태그(wjbid `pre-cr146-20261012`, `cr146-20261012`), 넘겨받지 않은 이미지, 볼륨, 빌드 캐시는 보지 않는다
- 태그가 더 있는 이미지는 태그만 떨어지고, 마지막 태그면 이미지가 지워진다
- `--dry-run` 이면 지울 대상만 찍는다
- 남길 개수가 숫자가 아니거나 1 보다 작으면, 이미지 이름이 없으면 아무것도 하지 않고 끝낸다

### 3.2 `deploy.sh`

- 남길 개수는 환경변수 `PRE_IMAGE_KEEP`(기본 2). 숫자가 아니거나 1 보다 작으면 배포를 시작하지 않는다
- `wjbid_prune_images`, `chaws_prune_images` 를 더하고, 각 배포가 healthy 를 본 뒤 그 이미지를 정리한다

| 대상 | 정리하는 이미지 |
|---|---|
| `chaws-be` | `aimbase-api` |
| `chaws-agent`, `chaws-agent-3plgw` | `aimbase-aimbase-agent` |
| `chaws-agent-wes-cs`, `chaws-agent-wes-assist` | `aimbase-aimbase-agent-wes-cs`, `aimbase-aimbase-agent-wes-assist` |
| `chaws-tts` | `aimbase-tts-sidecar` |
| `wjbid-sandbox`, `wjbid-be`, `wjbid-agent` | `aimbase-skill-sandbox`, `aimbase-api`, `aimbase-aimbase-agent` |

- healthy 가 되지 않아 멈춘 배포는 정리하지 않는다. 되돌릴 이미지가 그대로 남는다
- 정리가 실패해도 배포는 끝난 것으로 두고 한 줄만 찍는다
- 정리 스크립트는 서버에 올리는 것이 아니라 배포 도구라 `CHAWS_COMMIT` worktree 가 아니라 `deploy.sh` 와 같은 폴더 것을 쓴다

## 4. 남길 개수 기본값 2

- 되돌리기는 바로 앞 배포로 가는 것이라 1 개면 충분해 보이지만, chaws 는 실행기 둘(`aimbase-agent`, `aimbase-agent-3plgw`)이 이미지 이름 `aimbase-aimbase-agent` 하나를 같이 쓴다
- 같은 커밋을 두 실행기에 잇달아 올리면 태그가 둘 생긴다. 앞 것은 먼저 올린 실행기의 되돌릴 이미지, 뒤 것은 먼저 올린 실행기가 막 만든 이미지다. 1 개만 두면 먼저 올린 실행기의 되돌릴 이미지가 지워진다
- 11-19 chaws 에서도 `aimbase-agent-1` 은 태그 없는 앞 이미지(`758903a0b8d8`)로, `aimbase-agent-3plgw-1` 은 `latest`(`a5e0458b2c2d`)로 돌고 있었다
- 이미지 하나가 2.5GB 에서 3.9GB 라 chaws 이미지 다섯 종에 2 개씩 남겨도 지금 남은 53G 안에 든다

## 5. 시험

### 5.1 맥 도커 (2026-11-19)

빈 이미지 여섯을 만들어 pre- 태그 여섯, 사람이 붙인 `pre-cr146-20261012`, 다른 이미지 이름의 pre- 태그, `latest`, 옛 이미지를 쓰는 멈춘 컨테이너를 두고 남길 개수 2 로 돌렸다.

| 순번 | 확인 | 결과 |
|---|---|---|
| 1 | `--dry-run` | 지울 대상 3개만 찍고 이미지 수 그대로 |
| 2 | 남길 개수 0, `abc`, 이미지 이름 없음 | 아무것도 지우지 않고 끝 |
| 3 | 실제 실행 | 최근 2개 남김, 오래된 3개 지움, 컨테이너가 쓰는 태그 남김 |
| 4 | 다른 태그가 없던 이미지 | 이미지까지 지워짐 |
| 5 | `pre-cr146-20261012`, 다른 이미지 이름의 태그, `latest` | 그대로 |
| 6 | `PRE_IMAGE_KEEP=0`, `x` 로 `deploy.sh` 실행 | 배포 전에 멈춤 |
