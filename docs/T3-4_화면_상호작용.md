| 2 | 파일 칩 누르기 | 미리 볼 수 있는 파일이면 옆 창을 열고(좁은 위젯은 크게 보기로) 「미리보기를 만드는 중입니다」, 미리보기 정보를 받아 종류별 보기로 바꾼다. 아니면 내려받기(기존) | GET /chat/artifacts/preview |
| 3 | PAGES | pptx 는 첫 장, docx 와 pdf 는 보이는 쪽부터 그림을 받는다. 한 장 보기는 다음 장을 미리 받는다 | GET /chat/artifacts/preview/page |
| 4 | HTML, SVG, IMAGE, MARKDOWN, TEXT | 원본을 받아 그린다. HTML 은 격리 틀에서 실행 | GET /chat/artifacts/download |
| 5 | NONE, 오류 | 이유 문구와 내려받기 단추 | - |
| 6 | 내려받기 (옆 창 머리줄) | 원본을 받는다 | GET /chat/artifacts/download |
| 7 | 닫기, 새 대화 | 옆 창을 닫는다 | - |

## 작성 가이드

1. **작성 대상**: 3개 이상 필드 폼, 동적 필드, 실시간 갱신, 외부 연동 페이지만 기재
2. **단순 CRUD 제외**: 목록 조회 → 상세 → 수정 → 삭제만 있는 페이지는 T3-3으로 충분
3. **진입 조건**: 인증, 권한, 선행 조건 명시
4. **시나리오 테이블**: 단계별 사용자 행동 → 시스템 반응 → API 호출 매핑
