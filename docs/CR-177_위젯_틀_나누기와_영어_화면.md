## 4. 영어 화면 [PRD-401, PRD-402, BIZ-160, BIZ-161]

### 4.1 언어 정하기 (BIZ-160)

1. 사람이 더 보기 「화면 언어」에서 고른 값. 그 브라우저에만 기억한다(`aimbase-chat:locale`)
2. 붙이는 앱 옵션 `locale`(엘리먼트 속성 `locale`). `en-US` 처럼 지역이 붙으면 앞 두 글자로 본다
3. 한국어

받는 언어는 `ko`, `en` 둘이다. 그 밖의 값은 없는 것으로 본다.

### 4.2 언어를 바꿀 때

- 머리줄, 입력칸 안내, 단추 도움말, 메뉴, 첫 화면 안내와 추천 질문, 응답 아래 단추, 다시 생성 버전 표시를 바로 다시 그린다. 각 기능에는 `localeChange` 알림을 보낸다.
- 이미 대화 칸에 나온 질문, 응답, 회색 알림 줄은 그대로 둔다.
- 위젯 설정을 새 언어로 다시 받아 아쉬워요 이유 이름만 바꾼다. 다시 받기가 실패하면 앞 이름을 그대로 쓴다.
- 시각 표기(`HH:mm`, 다른 날은 `MM-DD HH:mm`)는 언어와 상관없이 같다.

### 4.3 문구표 (BIZ-161)

- 위젯 본체 문구는 `strings.ts` 의 문구표 하나(`defineStrings({ko, en})`)에 둔다. ko 와 en 의 키가 다르면 타입 검사에서 막힌다.
- 서버 오류는 위젯이 아는 오류 코드(`session_busy`, `model_not_allowed` 등)만 문구표 글로 바꾸고, 모르는 코드는 서버가 준 글을 그대로 보인다.
- 한국어 이름은 [T1-10 용어표](T1-10_용어표.md)를 따른다.

주요 화면 이름의 영어:

| 순번 | 한국어 | English |
|---|---|---|
| 1 | 새 대화 | New chat |
| 2 | 크게 보기 | Expand |
| 3 | 더 보기 | More |
| 4 | 닫기 | Close |
| 5 | 파일·자료 추가 | Add files |
| 6 | 파일 올리기 | Upload files |
| 7 | 화면 언어 | Language |
| 8 | 글자 크기, 작게, 보통, 크게 | Text size, Small, Medium, Large |
| 9 | 깊게 생각하기 | Extended thinking |
| 10 | 전송, 응답 중지 | Send, Stop |
| 11 | 복사, 다시 생성 | Copy, Regenerate |
| 12 | 좋아요, 아쉬워요 | Good response, Bad response |
| 13 | 맨 아래로 | Scroll to bottom |
| 14 | 무엇을 도와드릴까요? | How can I help? |
| 15 | 대화 목록 | Chats |

### 4.4 붙이는 앱이 주는 글

- `emptyTitle`, `emptySubtitle` 은 글 하나 또는 `{ "ko": "...", "en": "..." }`, `suggestions` 는 글 배열 또는 `{ "ko": [...], "en": [...] }` 이다.
- 엘리먼트 속성(`empty-title`, `empty-subtitle`, `suggestions`)도 같은 모양의 JSON 을 받는다. `empty-title` 이 `{` 로 시작하지 않으면 글 하나로 본다.
- 지금 언어 값이 없으면 한국어 값, 그것도 없으면 처음 값을 쓴다.

### 4.5 아쉬워요 이유 이름 (서버, PRD-402)

- 위젯 설정 조회에 `locale` 인자를 더한다. `GET /api/v1/chat/widget-settings?connection_id={id}&locale=en`
- 런타임 설정 `widget.feedback-reasons` 의 항목에 `labels` 칸을 더한다. `{"code": "WRONG_INFO", "label": "틀린 정보", "labels": {"en": "Incorrect information"}}`
- 응답 `feedback_reasons[].label` 은 `labels[locale]` 이 있으면 그 값, 없으면 `label` 이다. `locale` 이 없거나 `ko` 면 `label` 이다. 응답 모양은 바뀌지 않는다.
- 관리 화면의 응답 평가 목록은 지금처럼 `label`(한국어)을 쓴다.
