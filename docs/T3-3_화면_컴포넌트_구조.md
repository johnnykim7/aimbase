## 컴포넌트 구조 + API 매핑

### Chat (`/chat`, `/chat/:sessionId`) [CR-045/CR-046]

```
Chat
├── ChatSidebar (좌측, 대화방 목록)
│   ├── NewChatButton (+ 새 대화) → NewChatModal 열기 → POST 후 navigate(`/chat/{newId}`)
│   ├── ConversationList → GET /api/v1/conversations (deleted_at IS NULL)
│   │   └── ConversationItem (호버 시 휴지통 아이콘 노출)
│   │       ├── 클릭 → navigate(`/chat/{sessionId}`)
│   │       └── 휴지통 → DeleteConfirmModal → DELETE /api/v1/conversations/{id} (Soft Delete)
│   └── useMutation 성공 시 useQuery invalidate → 목록 즉시 갱신
├── ChatHeader (우측 상단)
│   ├── 세션 제목
│   ├── workspaceRef Badge
│   └── 모델/Connection 표시
├── MessageList (스크롤 영역)
│   ├── TextBlock / ThinkingBlock / ToolUseBlock / ToolResultBlock [CR-045]
│   └── 중단된 메시지: `[중단됨]` prefix + 회색 처리 [CR-046]
└── ChatInput (하단)
    ├── 입력창 (스트림 중에도 활성 — 끼어들기 허용) [CR-046]
    ├── 전송 버튼
    │   └── isStreaming 시: 자동 이전 abort → 새 요청 (옵션 B 자동 끼어들기)
    └── 중지 버튼 (isStreaming 시 표시)
        └── POST /api/v1/chat/{sessionId}/abort + FE AbortController 호출
```

**관련 훅**:
- `useChatStream` — fetch + ReadableStream SSE 파서 + AbortController + `/abort` API 호출 [CR-046 보강]
- `useConversation` — GET /api/v1/conversations/{id}
- `useDeleteConversation` — useMutation + invalidate

**관련 컴포넌트** (`components/chat/`):
- `NewChatModal`, `ConversationItem`, `DeleteConfirmModal`(신규 [CR-046]), `MessageBlock` 4종

```
        └── 모두 삭제                         목록이 있을 때만. 누르면 확인: 기억 n개를 모두 삭제할까요? 삭제 | 취소
```

- 모델과 깊게 생각하기 이어 쓰기(PRD-442)는 화면이 없다. 위젯 본체의 모델 선택과 깊게 생각하기 단추가 그대로 쓰인다.
- 위젯 폭이 좁아도(모바일, CS 화면 오른쪽 칸) 창은 위젯 판 전체를 덮으므로 크게 보기로 바꾸지 않는다.
- 문구는 기능 파일의 문구표(한국어, 영어)에 둔다. 메뉴, 창 이름은 T1-10 「기억과 선호」, 「내 선호」, 「자동 기억」.

### 신규 기능 파일 (위젯, CR-177 틀 사용법)

| 무엇 | 파일 | 자리 |
