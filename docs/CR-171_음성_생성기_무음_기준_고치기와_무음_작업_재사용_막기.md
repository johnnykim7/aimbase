## 1. 배경

피킹 화면이 상품 바코드 끝자리 1, 2, 6, 8 을 소리 없이 지나갔다. 59 저장분 「일」 「이」 「육」 「팔」 이 0.168초짜리 빈 파일이다. 네 건의 md5 가 모두 `36b38255` 로 같다(11-08 23:29 59 읽기 전용 조회).

## 2. 원인

| 순번 | 어디 | 무엇 |
|---|---|---|
| 1 | 생성기 검사 `check_audio` | 뒤처리 전 최대 진폭이 0.00001(-100 dB) 미만일 때만 거절한다. 모델이 낸 무음은 -98.9 dB 라 1번째 시도에 합격한다 |
| 2 | 뒤처리 `silenceremove` -50 dB | 그 소리를 전부 잘라 빈 파일만 남긴다. 합격 뒤의 일이라 시도 반복이 돌지 않는다 |
| 3 | 씨앗 고정(BIZ-134) | 같은 글은 몇 번을 만들어도 같은 빈 파일이다 |
| 4 | 재사용 `findReusable` | 끝난 빈 작업을 보관 기간 7일 동안 돌려줘 생성기에 닿지 않는다 |

## 3. 변경

1. 생성기: 무음 기준을 코드 상수에서 음색 설정 `silent_peak_db` 로 옮긴다. field-voice-07 은 -40 dB 다. 칸이 없으면 기동이 실패한다(다른 필수 칸과 같다). 거절하면 있는 시도 반복이 씨앗 + 1 로 다시 만든다.
2. api: 끝난 작업의 소리 길이가 `aimbase.tts.min-reusable-duration-sec`(기본 0.25초)보다 짧으면 같은 글을 다시 맡겨도 돌려주지 않고 새 작업을 만든다. 옛 행은 지우지 않고 보관 기간에 맡긴다. 새 작업이 더 최근이므로 그 뒤로는 새 작업을 돌려준다.

| 파일 | 변경 |
|---|---|
| `tts-sidecar/server.py` | `SILENT_PEAK` 상수를 없애고 음색의 값으로 검사한다 |
| `tts-sidecar/voices/field-voice-07/voice.json` | `silent_peak_db: -40` |
| `tts-sidecar/tests/test_server.py` | TC-TTS-152, 153 에 모델 무음(-98.9 dB)과 기준 위아래 |
| `TtsJobService.java`, `application.yml` | 재사용 판정과 설정 |
| `TtsJobServiceTest.java` | TC-TTS-117 |

## 4. 값을 정한 까닭

| 값 | 판단 |
|---|---|
| -100 dB(옛 값) | 모델 무음(-98.9 dB)이 합격한다 |
| -60 dB(bp-wms 맥 시험값 0.001) | 모델 무음은 걸러도 뒤처리 기준 -50 dB 아래라, -60 dB 와 -50 dB 사이의 소리가 합격하면 빈 파일이 남는다 |
| -50 dB | 뒤처리 기준과 같다. 뒤처리는 짧은 구간의 평균으로 판단하므로 최대 진폭이 -50 dB 를 살짝 넘는 소리도 잘릴 수 있다 |
| **-40 dB(채택)** | 뒤처리 기준보다 10 dB 위이고 bp-wms 저장 기준(최대 음량 -40 dB)과 같다. 59 저장분 정상 481건의 최대 음량 최저가 -14.6 dB 라(7.3) 여유가 25 dB 있다 |

생성기를 소비앱 기준과 맞췄으므로, 생성기가 합격시킨 소리를 bp-wms 가 버리고 같은 작업이 다시 돌아오는 일이 없다. 맥 실모델에서 네 글자 결과는 0.001 로 시험한 값과 같다(7.2).

음색 설정에 둔 까닭: 뒤처리 기준이 `voice.json` 에 있어 둘을 함께 봐야 한다. 생성기에는 DB 가 없고, 음색 폴더는 `./deploy.sh tts` 와 `chaws-tts` 가 이미 함께 보낸다.

## 5. 바뀌지 않는 것

- 맡기기, 조회 창구의 요청과 응답 모양. 세 번 모두 불합격하면 지금 계약대로 `FAILED` `generation_failed:silent_audio` 다
- 1번째 시도에 합격하던 문장의 소리. 씨앗과 생성값이 그대로이고 합격 기준만 올렸다. 기준 아래였던 소리는 뒤처리에서 어차피 전부 잘린다
- 옛 빈 작업을 번호로 조회하면 그대로 나온다. DB 를 고치지 않는다
- bp-wms 쪽 저장 전 검사와 저장분 정리는 CR-WMS-931 몫이다
