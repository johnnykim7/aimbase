## 0. 개요 / 한 줄

스캔 PDF·이미지에서 전통적 OCR(Tesseract)을 통해 텍스트를 뽑는 기능을 **완성**한다. 현재 `read_pdf(ocr_enabled=True)` 파라미터가 받아만 두고 본문에서 무시되는 반쪽 상태이며, 이미지 OCR MCP 툴은 존재하지 않는다. Vision 모델(CR-061) 우회와는 다른 결정론적/오프라인 OCR 경로를 정식 신설한다.

### 1.3 Vision 모델(CR-061) 과의 분리

| 축 | 전통적 OCR (CR-092) | Vision 모델 (CR-061) |
|---|---|---|
| 비용 | 0 (로컬) | 토큰 비용 |
| 정확도 | 한·영 인쇄체 양호, 손글씨 약함 | 손글씨/표/레이아웃 강함 |
| 결정론 | O (같은 입력→같은 출력) | X |
| 오프라인 | O | X |
| 사용처 | RAG 인제스션, 결정론 필요한 추출 | 채팅 대화/즉시 응답 |

**원칙**: 자동 라우팅하지 않는다. 호출자가 명시 선택. RAG 인제스션은 OCR 기본, 위젯 채팅은 Vision 기본. BE `PdfTextExtractor` 만 텍스트 0자 fallback 으로 OCR 자동 시도.

### 1.4 비즈니스 규칙 (신규)

| 규칙 | 값 | 사유 |
|---|---|---|
| **BIZ-105** OCR 페이지 상한 | `OCR_MAX_PAGES=50` (global_config) | 무한정 OCR 폭주 차단. 초과 시 처음 N 페이지만 OCR 하고 truncated 플래그 |

### 2.2 호출 흐름

#### Flow A — 스캔 PDF RAG 인제스션 (UC-1)
1. RAG ingestor → `parse_document(strategy=hi_res)` (unstructured 내부에서 tesseract 호출)
2. 단, hi_res 는 layout 분석 + OCR 동시 — 처리 시간이 길다. 이미 운영. **본 CR 영향 없음** (운영 검증만)

#### Flow B — BE PDF 첨부 fallback (UC-2)
```
ChatController(file upload)
  → AttachmentService.process(pdf_bytes)
  → PdfTextExtractor.extract(pdf_bytes)
        ├─ parse_document(base64, "pdf")  # 1차 (텍스트 박힌 PDF 빠름)
        │     └─ result.text.length() < 50 ?
        │          ├─ NO  → 그대로 반환
        │          └─ YES → fallback
        └─ read_pdf(base64, ocr_enabled=true, languages="kor+eng", max_pages=50)
              └─ pdfplumber pages 순회
                    ├─ page.extract_text() (텍스트 박힌 페이지)
                    └─ 텍스트 없거나 < 임계 → pdf2image.convert(page) → pytesseract.image_to_string()
```

#### Flow C — 이미지 OCR (UC-3, UC-4)
```
caller (model / workflow / Claude CLI)
  → mcp tool: ocr_image(file_base64, languages="kor+eng")
        → PIL.Image.open(io.BytesIO(bytes))
        → pytesseract.image_to_string(image, lang=languages)
        → {text, ocr_confidence_avg, success}
```

### 3.2 신규 모듈: `python-sidecar/src/rag_pipeline/tools/ocr.py`

```python
"""OCR helpers (CR-092). Tesseract via pytesseract + pdf2image."""
from __future__ import annotations
import base64, io
from typing import Any

# global_config 에서 주입
_DEFAULT_LANGUAGES = "kor+eng"
_DEFAULT_MAX_PAGES = 50
_DEFAULT_DPI = 300

# 운영 가이드 등록 화이트리스트 (BIZ-106)
_LANGUAGE_WHITELIST = {"eng", "kor", "jpn", "chi_sim", "chi_tra", "fra", "deu", "spa"}


def _validate_languages(languages: str) -> tuple[bool, str | None]:
    """`kor+eng` 같은 + 결합 lang code 검증."""
    parts = [p.strip() for p in languages.split("+") if p.strip()]
    for p in parts:
        if p not in _LANGUAGE_WHITELIST:
            return False, f"unsupported language: {p}. allowed={sorted(_LANGUAGE_WHITELIST)}"
    return True, None


def ocr_image_bytes(image_bytes: bytes, languages: str = _DEFAULT_LANGUAGES) -> dict[str, Any]:
    """단일 이미지 → 텍스트.
    Returns: {text, success, languages, error?}
    """
    ok, err = _validate_languages(languages)
    if not ok:
        return {"success": False, "error": err}
    try:
        import pytesseract
        from PIL import Image
    except ImportError as e:
        return {"success": False, "error": f"ocr_dependencies_missing: {e}"}
    try:
        img = Image.open(io.BytesIO(image_bytes))
        text = pytesseract.image_to_string(img, lang=languages)
        return {"text": text, "success": True, "languages": languages}
    except pytesseract.TesseractNotFoundError:
        return {"success": False, "error": "tesseract_not_installed"}
    except Exception as e:
        return {"success": False, "error": f"ocr_failed: {e}"}


def ocr_pdf_bytes(
    pdf_bytes: bytes,
    languages: str = _DEFAULT_LANGUAGES,
    max_pages: int = _DEFAULT_MAX_PAGES,
    dpi: int = _DEFAULT_DPI,
    page_text_min_chars: int = 20,
) -> dict[str, Any]:
    """PDF → 페이지별 OCR 텍스트.
    이미 텍스트가 박힌 페이지는 그것을 우선 사용 (pdfplumber.extract_text), 비어있을 때만 OCR.
    """
    ok, err = _validate_languages(languages)
    if not ok:
        return {"success": False, "error": err}
    try:
        import pytesseract
        from pdf2image import convert_from_bytes
        import pdfplumber
    except ImportError as e:
        return {"success": False, "error": f"ocr_dependencies_missing: {e}"}

    pages: list[dict[str, Any]] = []
    warnings: list[str] = []
    truncated = False

    with pdfplumber.open(io.BytesIO(pdf_bytes)) as pdf:
        total_pages = len(pdf.pages)
        if total_pages > max_pages:
            truncated = True
            target_pages = max_pages
        else:
            target_pages = total_pages

        # pdf2image 는 한 번에 변환 (페이지 범위 last_page 지정)
        try:
            images = convert_from_bytes(pdf_bytes, dpi=dpi, last_page=target_pages)
        except Exception as e:
            return {"success": False, "error": f"pdf2image_failed: {e}"}

        for idx in range(target_pages):
            page = pdf.pages[idx]
            embedded = page.extract_text() or ""
            if len(embedded.strip()) >= page_text_min_chars:
                pages.append({"page_number": idx + 1, "text": embedded, "source": "embedded"})
                continue
            try:
                img = images[idx]
                ocr_text = pytesseract.image_to_string(img, lang=languages)
                pages.append({"page_number": idx + 1, "text": ocr_text, "source": "ocr"})
            except Exception as e:
                warnings.append(f"page_{idx + 1}_ocr_failed: {e}")
                pages.append({"page_number": idx + 1, "text": "", "source": "failed"})

    return {
        "pages": pages,
        "page_count": len(pages),
        "total_pages": total_pages,
        "truncated": truncated,
        "languages": languages,
        "warnings": warnings,
        "success": True,
    }
```

    try:
        bytes_ = base64.b64decode(file_base64)

### 3.5 BE 수정: `PdfTextExtractor` fallback

```java
public ExtractResult extract(byte[] pdfBytes) {
    if (pdfBytes == null || pdfBytes.length == 0) return new ExtractResult("", null);
    String base64 = Base64.getEncoder().encodeToString(pdfBytes);

    // 1차: parse_document (텍스트 박힌 PDF 빠름)
    ExtractResult primary = tryParseDocument(base64);
    if (primary.text() != null && primary.text().length() >= ocrFallbackThreshold) {
        return primary;
    }

    // 2차: read_pdf(ocr_enabled=true) — BIZ-107
    log.info("PDF text < {} chars (got {}), falling back to OCR",
             ocrFallbackThreshold, primary.text() == null ? 0 : primary.text().length());
    try {
        Map<String, Object> ocrResult = client.readPdf(base64, false, true,
                ocrLanguages, ocrMaxPages);
        if (Boolean.TRUE.equals(ocrResult.get("success"))) {
            String text = joinPages(ocrResult);
            Integer pages = (Integer) ocrResult.get("page_count");
            if (text.length() > MAX_TEXT_LENGTH) {
                text = text.substring(0, MAX_TEXT_LENGTH) + "\n[... truncated ...]";
            }
            return new ExtractResult(text, pages);
        }
    } catch (Exception e) {
        log.warn("OCR fallback failed: {}", e.getMessage());
    }
    return primary;  // OCR 도 실패하면 1차 결과(빈 텍스트라도) 그대로
}
```

## 5. Non-Goals (이번 CR 에서 제외)

- 수식/표 구조 OCR (LaTeX-OCR, table-transformer) — 별도 CR
- 손글씨 OCR — 별도 CR (TrOCR 등 ML 모델)
- 다국어 자동 감지 (langdetect) — 명시 지정만
- OCR 진행률 SSE 스트리밍 — 별도 CR (위젯 UX)
- KnowledgeSource 의 OCR strategy 선택 UI — 후속 CR (현재는 unstructured 자체 strategy 사용)
