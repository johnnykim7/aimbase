## 1. 목적과 범위

### 1.1 목적
CR-058 위젯에 **음성 입력(STT)** 기능을 추가한다. 위젯 사용자는 마이크 버튼을 눌러 녹음하고, 녹음 종료 시 OpenAI Whisper API로 텍스트 변환된 결과가 **입력창에 자동 삽입**된다. 사용자는 삽입된 텍스트를 편집하거나 그대로 전송할 수 있다. 실시간 스트리밍이 아닌 **녹음 후 일괄 전송** 방식이다.

### 1.2 범위 — 포함 (Sprint 55, 4.5MD)
- Phase 1 — `global_config` master V19 seed + 키 상수 (0.5MD)
- Phase 2 — `SpeechService` 추출 + `SpeechController` 리팩터 + 회귀 (1.0MD)
- Phase 3 — `ChatSttController` + `SttRateLimiter` + `WidgetTokenController` scope + BIZ-102~104 (1.0MD)
- Phase 4 — 위젯 FE 마이크 UI + MediaRecorder + 파형 타이머 + `stt-client.ts` + Safari 폴백 (1.5MD)
- Phase 5 — 테스트 + 가이드 갱신 (0.5MD)

### 1.3 범위 — 제외
- **실시간 스트리밍 STT** — OpenAI Realtime API (별도 CR 후보 CR-063)
- **TTS 위젯 UI** — Assistant 응답 낭독 (별도 CR 후보 CR-064)
- **화자 분리 / 타임스탬프 세그먼트** — Whisper 기능은 존재하나 UI 미노출
- **오프라인 / 온디바이스 STT** — 전량 서버 경유
- **Whisper 외 프로바이더** — 현재 Whisper 프록시 구조만 지원

### 1.4 선행 의존성
- **CR-011** `SpeechController` (Whisper 프록시) — **SpeechService 로 추출 후 공유**
- **CR-040** `global_config` + `PlatformSettingsService` — 런타임 설정화에 재사용
- **CR-058** 위젯 토큰 체계(`widget.allowed-scopes`) — `chat:stt` 추가
- **CR-061** 위젯 API 패턴(`/chat/*` + 전용 scope + Rate Limit + 감사 로그) — 그대로 답습
- **브라우저 API**: `navigator.mediaDevices.getUserMedia` + `MediaRecorder` + `AudioContext`(파형 표시용)

### 2.2 왜 전용 엔드포인트인가

**기존 `/api/v1/speech/stt` 재사용을 버린 이유**:
1. **보안 레이어 불일치** — 기존은 Platform 사용자 JWT 기반. 위젯은 `widget-token`(JWT + `scope` claim). 둘 다 허용하려면 Security config 분기 + `@PreAuthorize` 다형화 필요 → 복잡도가 전용 컨트롤러 신설보다 높다
2. **테넌트 컨텍스트 해상도** — 기존은 `connectionRepository.findAll()` 전수 조회. 위젯 토큰은 테넌트가 명시되어 있어 `TenantContext` 기반 조회가 자연스러움
3. **Rate Limit 분리** — 위젯 호출은 세션당 10req/min, Platform 관리자 호출은 무제한(감사만). 한 컨트롤러에서 분기 시 로직 이원화가 오히려 복잡
4. **CR-058/CR-061 API 패턴 일관성** — `/chat/completions`, `/chat/attachments`, `/chat/workflows/...` 모두 `/chat/*` 네임스페이스. STT만 예외가 되면 SDK 설계 깨짐

**대신** `SpeechService` 를 추출해 Whisper API 호출·multipart 조립·에러 매핑 로직은 **100% 공유**한다. 코드 중복 0.

### 2.3 왜 녹음 후 일괄 전송인가

OpenAI Whisper API(`/v1/audio/transcriptions`)는 **스트리밍 입력을 지원하지 않는다**. Realtime API(`/v1/realtime`)는 별도 프로토콜·별도 과금·별도 모델로, 구조 변경이 크다. 본 CR은 Whisper 경로만 다룬다. Realtime은 CR-063 후보로 분리.

## 4. API 설계

### 4.1 POST /api/v1/chat/stt (신규, 위젯 전용)

**인증**: Bearer `widget-token`, scope `chat:stt` 필수
**Content-Type**: `multipart/form-data`

**Form Fields**:
| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `file` | binary | ✅ | 오디오 파일. MIME 은 `widget.stt.allowed-mime-types` 허용 목록 |
| `language` | string | ❌ | `auto` / `ko` / `en` / ... (Whisper ISO-639-1). 기본 `widget.stt.default-language` |
| `session_id` | string | ❌ | 감사 로그 기록용. 없으면 JWT claim `session_id` 사용 |

**성공 응답 200**:
```json
{
  "success": true,
  "data": {
    "text": "안녕하세요 오늘 날씨가 좋네요",
    "language": "ko",
    "duration_sec": 3.4
  }
}
```

**에러 응답**:
| HTTP | code | 의미 |
|------|------|------|
| 400 | `STT_INVALID_MIME` | magic number 검증 실패 |
| 400 | `STT_FILE_TOO_LARGE` | BIZ-103 초과 |
| 400 | `STT_FILE_TOO_LONG` | BIZ-102 초과(Whisper 응답의 duration 기준 사후 판정) |
| 403 | `STT_SCOPE_FORBIDDEN` | `chat:stt` 없는 토큰 |
| 429 | `STT_RATE_LIMITED` | BIZ-104 초과 |
| 503 | `STT_PROVIDER_UNAVAILABLE` | OpenAI Connection 미설정 또는 Whisper API 5xx |

### 5.3 ChatSttController

```java
@RestController
@RequestMapping("/api/v1/chat")
public class ChatSttController {

  private final SpeechService speechService;
  private final SttRateLimiter rateLimiter;
  private final MimeValidator mimeValidator;
  private final PlatformSettingsService settings;
  private final AuditLogService auditLog;

  @PostMapping(value = "/stt", consumes = MULTIPART_FORM_DATA_VALUE)
  @PreAuthorize("hasAuthority('SCOPE_chat:stt')")
  public ResponseEntity<ApiResponse<?>> transcribe(
      @RequestPart("file") MultipartFile file,
      @RequestParam(value = "language", required = false) String language,
      @RequestParam(value = "session_id", required = false) String sessionId,
      @AuthenticationPrincipal Jwt jwt) throws IOException {

    String sid = sessionId != null ? sessionId : jwt.getClaimAsString("session_id");

    // 1. Rate limit
    rateLimiter.checkAndIncrement(sid); // 초과 시 SpeechException(RATE_LIMITED)

    // 2. MIME 재검증 (magic number)
    String mime = mimeValidator.detectAudioMime(file.getBytes());
    List<String> allowed = settings.getList("widget.stt.allowed-mime-types");
    if (!allowed.contains(mime)) throw SpeechException.invalidMime(mime);

    // 3. 크기
    long maxBytes = settings.getLong("widget.stt.max-size-bytes");
    if (file.getSize() > maxBytes) throw SpeechException.tooLarge(file.getSize(), maxBytes);

    // 4. 언어 기본값
    String lang = language != null ? language : settings.getString("widget.stt.default-language");

    // 5. Whisper 호출
    TranscribeResult r = speechService.transcribe(file.getBytes(), mime, file.getOriginalFilename(), lang);

    // 6. 녹음 시간 사후 제한 (Whisper duration 응답 기준)
    long maxDur = settings.getLong("widget.stt.max-duration-seconds");
    if (r.durationSec() != null && r.durationSec() > maxDur)
      throw SpeechException.tooLong(r.durationSec(), maxDur);

    // 7. 감사 로그 (본문 제외)
    auditLog.record("STT_TRANSCRIBE", Map.of(
        "session_id", sid,
        "duration_sec", r.durationSec(),
        "size_bytes", file.getSize(),
        "language", r.language(),
        "mime_type", mime
    ));

    return ResponseEntity.ok(ApiResponse.ok(r));
  }
}
```

### 5.4 SttRateLimiter

```java
@Component
public class SttRateLimiter {
  private final StringRedisTemplate redis;
  private final PlatformSettingsService settings;

  public void checkAndIncrement(String sessionId) {
    int limit = settings.getInt("widget.stt.rate-limit-per-minute");
    String key = "stt:rate:" + sessionId;
    Long count = redis.opsForValue().increment(key);
    if (count == 1L) redis.expire(key, Duration.ofMinutes(1));
    if (count > limit) throw SpeechException.rateLimited(limit);
  }
}
```

### 6.2 stt-client.ts 스케치

```ts
export interface SttResult { text: string; language: string; duration_sec: number; }

export class SttClient {
  constructor(private baseUrl: string, private getToken: () => Promise<string>) {}

  async transcribe(blob: Blob, sessionId: string, language = 'auto'): Promise<SttResult> {
    const token = await this.getToken();
    const form = new FormData();
    form.append('file', blob, 'rec.webm');
    form.append('language', language);
    form.append('session_id', sessionId);

    const res = await fetch(`${this.baseUrl}/api/v1/chat/stt`, {
      method: 'POST',
      headers: { Authorization: `Bearer ${token}` },
      body: form,
    });
    if (!res.ok) {
      const err = await res.json().catch(() => ({}));
      throw new SttError(err.error?.code ?? 'STT_UNKNOWN', err.error?.message ?? res.statusText, res.status);
    }
    return (await res.json()).data as SttResult;
  }
}

export class SttError extends Error {
  constructor(public code: string, message: string, public status: number) { super(message); }
}
```

**MediaRecorder 훅 스케치**:
```ts
async function startRecording(): Promise<MediaRecorder> {
  if (!window.isSecureContext) throw new Error('STT requires HTTPS or localhost');

  const stream = await navigator.mediaDevices.getUserMedia({ audio: true });

  // 포맷 협상 — WebM/Opus 우선, Safari는 mp4/aac
  const mimeType = MediaRecorder.isTypeSupported('audio/webm;codecs=opus')
    ? 'audio/webm;codecs=opus'
    : MediaRecorder.isTypeSupported('audio/mp4')
    ? 'audio/mp4'
    : '';

  const rec = new MediaRecorder(stream, mimeType ? { mimeType } : undefined);
  const chunks: Blob[] = [];
  rec.ondataavailable = (e) => chunks.push(e.data);

  rec.onstop = async () => {
    stream.getTracks().forEach(t => t.stop()); // 마이크 LED off
    const blob = new Blob(chunks, { type: rec.mimeType });
    try {
      const result = await sttClient.transcribe(blob, sessionId);
      insertTextAtCursor(inputEl, result.text);
    } catch (e) { renderSttError(e); }
  };

  rec.start();
  return rec;
}
```

### 6.4 권한 거부/비활성 UX

| 상황 | UX |
|------|-----|

| Rate Limited (429) | "잠시 후 다시 시도해주세요 (분당 10회 제한)" |

### 6.5 접근성

- 마이크 버튼 `aria-label="음성 입력 시작"` / 녹음 중 `aria-label="녹음 정지"` `aria-pressed="true"`
- 오버레이 `role="status"` `aria-live="polite"` — 타이머 변화 스크린리더에 읽히도록
- 키보드 접근: `Space` 로 시작/정지, `Escape` 로 취소

## 7. 보안

### 7.1 다층 방어
1. **클라 선제** — HTTPS 검증 / 크기 / MIME
2. **JWT scope** — `@PreAuthorize("hasAuthority('SCOPE_chat:stt')")`
3. **magic number MIME** — `MimeValidator.detectAudioMime()`
4. **Rate Limit** — Redis INCR (세션당 10/min)
5. **CORS** — CR-058 위젯 설정 재사용
6. **OpenAI 키 접근** — 테넌트 Connection 테이블 경유 (직접 노출 없음)

### 7.2 프라이버시
- **오디오 바이너리 미저장** — 서버 임시 메모리만 거침
- **변환 텍스트 본문 감사 로그 제외** — 메타데이터만 기록
- **OpenAI 데이터 정책** — 소비앱/테넌트 관리자 책임 (OpenAI Connection 등록 시 안내 문구)

## 9. 마이그레이션/호환성

### 9.1 기존 `/api/v1/speech/stt` 영향
**무변경**. 내부 `SpeechService` 주입으로 리팩터만. 회귀 테스트 2건으로 동등성 보장.

### 9.2 기존 위젯 토큰 영향
기존 토큰은 `chat:stt` 스코프가 없어 **마이크 버튼 disabled 처리**. 새 토큰을 발급받아야 기능 활성화. FE 는 토큰 응답의 `scopes` 배열을 읽어 버튼 렌더 여부 결정.

### 9.3 Flyway 주의
`global_config.widget.allowed-scopes` 를 `||` 로 문자열 append 하는 UPDATE 는 기존 값 보존. 테스트 환경에서 수동 적용 스니펫을 운용 가이드 § 2-7 에 포함한다.
