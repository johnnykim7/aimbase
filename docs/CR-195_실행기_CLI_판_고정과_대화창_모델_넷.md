# CR-195: 실행기 CLI 판 고정과 대화창 모델 넷

- 발번: 2026-11-16
- 요청: 컨타 3plcore-529 (CR-194 후속, 사용자 01:37 모델 넷 승인, 01:50 CLI 판 올리기 ①)
- 원본 요구사항: [origins/원본_요구사항_CR195_실행기_CLI_판_고정_20261116.md](origins/원본_요구사항_CR195_실행기_CLI_판_고정_20261116.md)

## 1. 문제

- 실행기 이미지는 CLI 판을 정하지 않고 받는다. 59 와 운영 실행기는 이미지를 만든 날의 판인 2.1.197 에 머물러 있다.
- 2.1.197 은 Opus 5.5 와 Fable 5.2 를 400 으로 거절한다. 그래서 BO2 일반 화면 대화창은 Sonnet 5.5, Haiku 5.5 둘만 두었다.
- 2.1.197 은 깊게 생각하기를 끄라는 신호를 API 의 `thinking: disabled` 로 보내고 5.5 모델은 이것을 400 으로 거절한다. 다음 질문 제안은 생각을 끄고 부르므로 59 에서 502 가 났다(CR-194 10절 02:45).

## 2. 바꾸는 것

1. 실행기 이미지와 api 이미지의 CLI 판을 2.1.325 로 고정한다(`ARG CLAUDE_CODE_VERSION`).
2. 실행기가 CLI 를 기동할 때 `--thinking-display summarized` 를 준다. 2.1.325 는 이것이 없으면 생각 내용을 빈 글로 보내 대화창 생각 칸(CR-175)이 붙지 않는다. 2.1.197 도 이 옵션을 받는다(로컬 실측).
3. 일반 화면 실행기 연결(wes-assist)의 모델을 Opus 5.5, Fable 5.2, Sonnet 5.5, Haiku 5.5 로 두고 기본을 Opus 5.5 로 한다(`chaws-bootstrap.sh`).

## 3. 영향

- 실행기 `ClaudeCliCommandBuilder`(기동 옵션 하나), `ClaudeCliWorker`(값 한 줄), 이미지 `backend/aimbase-agent/Dockerfile`, `backend/platform-core/Dockerfile`, 운영 스크립트 `chaws-bootstrap.sh`.
- 이미지의 Node 는 18 이고 2.1.325 꾸러미는 Node 22 이상을 적어 둔다. 설치 때 경고만 나고, 실행 파일이 Node 를 쓰지 않는 자체 실행 파일이라 동작에는 영향이 없다(로컬 linux/amd64 이미지로 `claude --version` 2.1.325 확인). Node 판 올리기는 다른 도구에 걸려 이 CR 에 넣지 않는다.
- CS 실행기 연결의 모델 목록은 컨타가 직접 고친다(01:37 알림). 이 CR 은 일반 화면 연결만 바꾼다.
- 설계서: 기능과 규칙이 바뀌지 않아 T1, T3 은 고치지 않는다. 단위시험 하나를 더한다(`thinking_display_only_with_stream_json_and_value`).
