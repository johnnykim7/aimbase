즉 **엔진은 있는데 사용자 눈에 안 보이는** 상태. Claude Code 수준의 자연스러운 위임 UX로 끌어올린다.

## 4. 목표 (Outcome)

사용자가 챗 UI에서 자연스럽게 서브에이전트 위임 흐름을 경험한다:

4. 서브에이전트 완료 시 블록이 **완료 상태로 전환** + 요약 결과 표시
5. 메인 컨텍스트는 요약만 받아 토큰 효율 유지

## 5. 범위 (Phase 구성)

### Phase 0. 선행 확인 (✅ 완료, 2026-04-24)
- TaskCreateTool과 SubagentRunner 연결 실태 확인 결과:
  - **결합 누락 확정**. `TaskCreateTool.execute()`(line 66-113)는 `SubagentRunEntity`를 RUNNING 상태로 DB에 저장만 하고 `SubagentRunner.run()`을 호출하지 않음.
  - 클래스 주석은 "SubagentRunner를 래핑하여 Task 인터페이스를 제공"이라 적혀 있으나 실제 래핑 부재.
  - SubagentRunner 호출처는 `AgentOrchestrator`(병렬/순차) + `SubagentController`(REST `/subagents`)뿐.
  - 결과: Task 도구로 만든 작업은 영원히 RUNNING 상태로 남고 실행되지 않음.
- → **Phase 0.5 신설**: TaskCreateTool에서 `SubagentRunner.run(req)`를 Virtual Thread로 비동기 호출 + 실패 시 status FAILED 전환.

### Phase 0.5. TaskCreateTool ↔ SubagentRunner 결합 (0.5d)
- `TaskCreateTool.execute()`에 `SubagentRunner` 의존성 주입
- DB 저장 직후 `CompletableFuture.runAsync(() -> subagentRunner.run(req), virtualThreadPool)` 호출
- 실패 시 entity status를 FAILED로 업데이트 (예외 캡처)
- `runAsync` 결과는 fire-and-forget — `task_get`/`task_output`으로 추적
- 테스트: `TaskCreateToolTest`에 비동기 실행 검증 추가

### Phase 1. Built-in Agent 프롬프트 고도화 (1.5d)
- EXPLORE: 심도 3단계(quick/medium/thorough) + 탐색 전략(병렬 Grep/Glob, 파일 우선순위) + 결과 요약 규격(절대경로:줄번호, 스니펫, 200단어 이내)
- PLAN: 산출물 구조(단계 목록, 위험, 롤백), 코드 수정 금지 명시
- GENERAL: 도구 선택 기준, 위임 판단 가이드
- GUIDE/VERIFICATION: 도메인 체크리스트 템플릿
- DB UPDATE + Flyway 마이그레이션 동시 생성 (CLAUDE.md 규칙)
- 참고 소스: Claude Code 시스템 프롬프트 구조, OpenClaude 포트 흔적

### Phase 2. BE SSE 라이프사이클 이벤트 추가 (✅ 완료, 2026-04-24)
- `StreamEvent` 서브타입 2종 추가: `SubagentStart(runId, agentType, description)`, `SubagentDone(runId, status, summary, durationMs)`
- `SubagentRunner`에 ThreadLocal `STREAM_SINK` 도입 + `setStreamSink/clearStreamSink` 정적 API. 부모 VT의 sink를 자식 VT(백그라운드 실행)로 캡처 전달.
- `runBackground`에서 자식 VT 시작 시 `STREAM_SINK.set(capturedSink)` + `finally`에서 clear.
- `ChatController.streamResponse()` 단일 `sseSink` 람다로 통합 — `orchestrator.chatStream`과 `SubagentRunner.setStreamSink`가 같은 emitter를 공유.
- 컴파일 BUILD SUCCESSFUL.

### Phase 3. 사전 안내 자동 주입 (✅ 완료, 2026-04-24)
- `SubagentRunner.run()` 진입점에서 `SubagentStart` 발행 직전에 `TextDelta` 한 줄 주입.
- `buildPreamble(SubagentRequest)`가 `"\n> {TypeLabel} 서브에이전트로 '{description}' 시작합니다.\n\n"` 생성.
- 문구 외부화는 DB 정체 해결 후 Phase 3.1에서 `prompt_templates`로 이관 (현재는 하드코딩).

### Phase 4. FE Task 블록 렌더 (✅ 완료, 2026-04-24)
