# 원본 요구사항 CR-145: MCP 서버 등록에 머리글 싣기

- 접수: 2026-10-11
- 요청: 입찰대행 플랫폼(bidding-agency-platform) CR-144 정할 것 1 ①, 그 레포 컨트롤타워 2026-10-11 12:28 승인
- 근거 문서(입찰대행 레포): `docs/CR-144_Aimbase_가_부르는_통로에_열쇠_확인_넣기.md` 3절

## 원문

> Aimbase 에 등록에 머리글 싣기를 그 레포 CR 로 요청하고, 우리는 X-API-Key 머리글을 본다

## 배경

입찰대행 플랫폼은 Aimbase 에 열어 둔 MCP 통로(/mcp, /mcp/sse, /mcp/message)를 Aimbase 만 부를 수 있게 열쇠 확인을 넣는다.
Aimbase 는 MCP 서버 등록에서 주소만 읽어 연결하고 머리글을 싣지 못한다. 주소 물음표 뒤 값도 연결할 때 버린다.

## 요구

- 등록 config 에 머리글(이름과 값)을 받아 SSE 연결, 메시지 보내기, Streamable 모두에 싣는다
- 머리글이 없는 기존 등록은 지금처럼 동작한다
- 머리글 값은 비밀이다. 등록 조회 응답과 로그에서 값을 가린다
- 첨부 내려받기(DownloadFileTool)는 범위가 아니다. 입찰대행이 서명 주소로 따로 푼다
- Aimbase 운영 서버에서 입찰대행 8183 에 닿지 못하는 망 문제는 입찰대행 쪽 새 CR 이 다룬다
