# 원본 요구사항 CR-143: 워크플로우 LLM_CALL 구조화 출력 검증과 재시도

- 접수: 2026-10-10
- 발견 경위: LexFlow 서면 초안 워크플로우(`lexflow-draft`) 연동 검증 중 운영에서 재현

## 현상

운영 lexflow 테넌트에서 부록 D-2(소장) 사건자료로 워크플로우를 실행했다 (run `ba76c96a-0c35-4f7b-aca3-afac1ca60490`).

- run 상태는 `completed`
- `stepResults.final` 에 `structured_data` 가 없음. `output` 에 원문 텍스트만 있음
- 원문은 JSON 형태였으나 `html` 문자열 값 안에 이스케이프하지 않은 큰따옴표(`"매출 회복 후 일괄 지급하겠다"`)가 있어 파싱 실패
- 같은 워크플로우의 D-1(내용증명), 사건 개요 빈 건은 `structured_data` 가 정상으로 붙음

소비앱은 `completed` 를 성공으로 보고 `structured_data.html` 을 읽으므로, 빈 초안이 성공으로 전달된다.

## 요구

BIZ-034 대로 처리한다. response_schema 를 선언한 LLM_CALL 은 스키마를 만족하는 결과만 성공으로 넘기고,
만족하지 못하면 최대 2회 다시 요청하며, 그래도 실패하면 스텝을 실패로 끝낸다.
