## 결정 뒤 확인한 것 (설계 근거)

- 연속 10회(입찰대행 CR-169 창 회신의 run id) 모두 get_proposal_design_input 결과가 CLI 에 8,084자로 도착했다(8,000자 + 생략 안내). 실행 기록 본문의 생략 안내는 원본 81,881자 가운데 8,000자만 보이고 73,881자를 뺐다고 적었다
- 입찰대행 앱의 MCP 응답 코드에는 자르는 곳이 없다
- CLI 2.1.197 은 MCP 결과를 두 번 거른다. (1) 25,000 토큰(`MAX_MCP_OUTPUT_TOKENS`)을 넘으면 파일로 저장하고 알림만 준다 (2) 도구 하나 결과가 50,000자를 넘으면 파일로 저장하고 앞 2KB 만 준다. 도구 목록의 그 도구에 `_meta["anthropic/maxResultSizeChars"]` 가 있으면 (1)을 건너뛰고 (2)의 상한을 그 값(최대 500,000)으로 쓴다
- 로컬 실측(실제 CLI 2.1.197, 81,881자를 돌려주는 가짜 MCP 서버, AIMBASE 처럼 Read 봉인): 표시 없음은 (1)로 파일 저장 알림, `MAX_MCP_OUTPUT_TOKENS=100000` 은 (2)로 2KB 미리보기, 표시 200000 은 81,881자를 그대로 받았다
- AIMBASE 모드는 CLI 의 Read 를 봉인하므로(CR-126) 파일로 돌린 결과를 모델이 읽지 못한다. 그래서 "CLI 장치에 맡긴다"는 도구 목록에 크기 표시를 다는 것으로 한다
