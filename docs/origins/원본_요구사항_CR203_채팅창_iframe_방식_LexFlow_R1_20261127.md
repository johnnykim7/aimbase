## 4. 참고 (AI 파트 답변 초안, 아직 보내지 않음)

`~/Documents/GitHub/lexflow/docs/LexFlow_AI채팅창_연동_검토회신_답변_2026-11-27.html` 1장 R1 행과 4장 7번 행.

- 지금 채팅창은 iframe 방식을 제공하지 않는다. 화면에 포함된 스크립트가 `<aimbase-chat>` 요소를 만드는 구조다. 채팅창이 LexFlow 화면에서 받는 정보는 토큰 발급 함수와 화면 자료 함수의 반환값으로 한정되고 브라우저 저장소의 LexFlow 로그인 정보를 읽지 않는다. 다만 같은 출처 스크립트라는 구조상 기술적 접근 가능성은 지적대로다.
- iframe(별도 출처) 방식은 추가 개발 항목이다. 채팅창 페이지를 Aimbase 가 제공하고 토큰, 화면 자료, 화면 키를 메시지 통신(postMessage)으로 전달하는 구조가 필요하다. 규모 「대」, 일정은 내부 검토 후 회신.
