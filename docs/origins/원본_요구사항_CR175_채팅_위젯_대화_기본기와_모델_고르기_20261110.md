## 3. 정한 것

- 화면 색은 무채색(회색 계열)으로 간다. 소스는 고쳤고 빌드는 아직이다.
- CR 을 성격별로 나눠 한 창에서 차례로 설계, 구현한다. 모든 CR 이 같은 위젯 파일을 고쳐서 동시에 돌리지 않는다.

| 순번 | CR | 담는 기능 |
|---|---|---|
| 1 | CR-175 대화 기본기와 모델 고르기 + 화면 정리 | 1 ~ 9, 11, 12, 15, 16, 20, 21번, 무채색, 글자 크기 설정 |
| 2 | CR-176 지난 대화와 프로젝트 묶기, 기억 | 10, 26번 |
| 3 | CR-177 문서 출력과 미리보기 | 18, 27 ~ 37번 (HTML 보기 포함) |
| 4 | CR-178 위젯 안 승인 | 13번 |
| 5 | CR-179 음성 | 22, 23번 (CR-063, CR-064 를 다시 연다) |
| 6 | CR-180 첨부, 수식, 내보내기, 영어 화면 | 14, 17, 19, 25번 |

- 24번 상담원 연결은 뺀다. AI 대화를 사람에게 이관하는 기능인데 이 화면은 이미 상담원이 쓰는 화면이라 쓸 일이 없다.
- 모양은 실화면 목업(「현재」, 「개선안」 두 탭)으로 정했고 사용자가 확인했다. 본문 글자 크기는 더 보기 메뉴의 설정으로 바꾼다.
- 모델은 고를 수 있게 한다(6번 원문). 「깊게 생각하기」를 함께 둔다.
