## 확정 범위 (풀세트)
1. 마크다운 전체 렌더 (볼드/헤딩/리스트/인용/링크/인라인코드)
2. 표 렌더 + 표별 [CSV] [엑셀(.xlsx)] [복사] 다운로드 버튼 (클라이언트 변환 = claude.ai 방식)
3. 코드블록: 문법 하이라이트 + 복사 버튼
4. mermaid 도식화 (```mermaid``` 블록 → 다이어그램)
5. 디자인 개선 (여백/폰트/말풍선/표/코드 스타일)

## 설계 결정
- **렌더 시점**: 스트리밍 중 `textContent`(빠름), `done` 시 마크다운 최종 렌더로 1회 교체 (부분 마크다운 깨짐 방지)
- **XSS**: DOMPurify로 sanitize (Shadow DOM이라도 방어)
- **번들**: mermaid(~500KB), highlight.js는 lazy dynamic import — 평소 번들 ~40KB만 증가
- **표 엑셀**: SheetJS(xlsx) 또는 경량 자작 변환 — lazy load
- 전부 위젯 순수 프론트 작업. BE 무관.

## 코드 기준점 (실측)
- `packages/chat-widget-embed/src/widget.ts:682` — delta textContent (스트리밍 중 원문 출력)
- `packages/chat-widget-embed/src/widget.ts:698` — done 이벤트 (★여기서 최종 마크다운 렌더로 교체)

- `packages/chat-widget-embed/src/styles.ts` — Shadow DOM CSS (여기에 표/코드/헤딩/blockquote 스타일 추가)
- 현재 마크다운 렌더러/의존성 전무 (package.json devDeps: tsup/typescript 뿐, 런타임 deps 0)

## 착수 시 할 일 (독립 세션용)
1. deps 추가: `marked` + `dompurify` (표/코드/도식 lazy 대상은 highlight.js, mermaid)
2. 렌더 함수: markdown → sanitize(DOMPurify) → innerHTML. done 시 1회 교체
3. 표: 렌더된 `<table>` 위에 [CSV][엑셀][복사] 버튼 삽입 (클라이언트 변환, SheetJS lazy 또는 자작)
4. 코드블록: 하이라이트(highlight.js/lib/common lazy) + 복사 버튼
5. mermaid: ```mermaid``` 블록 → dynamic import 로 lazy 렌더
6. styles.ts: 표/코드/헤딩/인용/링크 CSS (다크모드 변수 대응)
7. 빌드: `cd packages/chat-widget-embed && npm run build` → dist 갱신 → static/widget 배포

## 주의
- Shadow DOM 안이라 스타일 격리됨. 전역 CSS 오염 걱정 없음
- 스트리밍 중 부분 마크다운은 깨지므로 done 시점에만 최종 렌더 (중간엔 textContent 유지)
- XSS: 반드시 DOMPurify. LLM 출력에 `<script>`/onerror 섞일 수 있음
