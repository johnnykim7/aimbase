## 2. 실측 (2026-10-13~14)

- 로컬: 키나 토큰 없이 `/admin-mcp?tenant_id=cr147a` 에 MCP 로 붙어 create_workflow 를 불렀고 워크플로우가 만들어졌다(CR-149 실측 스크립트).
- 보안 설정: `/sse/**`, `/admin-mcp/**` 가 인증 없이 열려 있다(SecurityConfig, 2026-03-29 c8dc5c9 부터). 같은 서버의 도구 MCP `/mcp/**` 는 X-API-Key 인증을 거친다.
- 운영: 이 맥에서 운영 서버 api 포트(8280)의 `/actuator/health` 가 200, `/admin-mcp` 가 400(세션 없는 요청 거부, 인증 요구 없음)으로 응답했다. 인터넷 전체에 열려 있는지는 방화벽 설정을 보지 않아 확인하지 못했다.
- 다룰 수 있는 것: 관리 도구 14개 전부. 연결, 지식, 프롬프트, 스키마, 정책 목록 조회, 워크플로우 생성, 수정, 삭제, 실행, 실행 승인.
- 테넌트 결정: 연결 주소의 `tenant_id` 를 그대로 믿고 세션에 묶는다(McpTenantSessionFilter). 인증을 붙여도 키의 테넌트와 주소의 테넌트를 대조하지 않으면, A 테넌트 키로 B 테넌트를 다룰 수 있다.
- 쓰는 곳: AXOPM(dev-labs/axopm-v5) `.mcp.json` 이 `http://59.8.160.12:8280/admin-mcp/sse?tenant_id=axopm_companyA` 를 키 없이 등록해 두었다(2026-04-14). CR-124 이전의 SSE 주소다.
- 규칙: BIZ-045 는 관리 도구가 REST API 와 같은 권한, 검증을 거친다고 정하고 있다. 지금은 접속 단계에서 이를 어긴다.
