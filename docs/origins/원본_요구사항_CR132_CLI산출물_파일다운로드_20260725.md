# CR-132 원본 요구사항 — CLI 산출물(pptx/xlsx/pdf/docx) 위젯 다운로드

## 발생 맥락
- 2026-07-25. bp-wes 자율주행 테스트 중. 위젯 사용.
- 사용자가 claude.ai/ChatGPT처럼 "제안서 pptx / 매출자료 xlsx / 보고서 pdf 를 예쁘게 만들어 다운로드"를 요구.
- (첨부: 새마을ON 제안서 PDF 수준의 산출물을 위젯에서 뽑고 싶다는 예시)

## 핵심 방향 (사용자 확정)
> "제가 CLI를 만들 수는 없잖아요. 그러니 CLI로 구동하되... 우리 WES/WMS 자료만 충분하게 전달하는 역할이죠."
> "경로 A — CLI에 이미 있는 걸 쓴다 (거의 공짜) → 당연하죠 난 그거 얘기한 건데"

- **파일 생성 능력은 Claude CLI가 이미 가짐** (Bash 로 python-pptx/openpyxl/reportlab 실행). aimbase 가 도구를 새로 만들지 않는다.
- **aimbase 몫은 딱 2가지**: ① CLI 가 파일 만들 런타임을 깔아주고, ② 만든 파일을 위젯이 다운로드받게 다리를 놓는다.

## 실측 결과 (2026-07-25)

### (1) 파일 생성 런타임 — 현재 없음 (막힘) ★
- 러너 Dockerfile `backend/aimbase-agent/Dockerfile`: `curl poppler-utils postgresql-client nodejs` 만 설치.
- **python3·pip·python-pptx·openpyxl·reportlab·python-docx 전무** → 지금 CLI 가 pptx 생성 시도하면 `python: not found` 실패.
- aimbase 네이티브 builtin 도구 36개에도 BashTool/FileWriteTool/파일생성 도구 없음 (ParseDocumentTool=읽기 전용). → CLI 경로가 유일.

### (2) CLI 작업 디렉토리 (cwd) — 배선 있음
- `working_directory` 필드가 platform-core → 러너 → Worker `pb.directory()` 로 CLI cwd 설정됨.
  - `backend/platform-core/src/main/java/com/platform/llm/adapter/ClaudeCliRunnerClient.java:266-274`
  - `backend/aimbase-agent/src/main/java/com/platform/agent/runner/dto/RunnerChatRequest.java:53-57`
  - Worker spawn: `backend/cli-runner/src/main/java/com/platform/runner/claudecli/ClaudeCliWorker.java`
- → CLI 가 파일 쓰면 이 폴더에 떨어지게 만들 수 있음. (산출물 폴더 지정 가능)

### (3) 위젯 다운로드 다리 — 없음
- 첨부는 업로드 전용: `backend/platform-core/src/main/java/com/platform/api/AttachmentController.java:31` (`@PostMapping multipart`).
- CLI 산출물을 내려받는 GET/다운로드 API 없음. 위젯(`packages/chat-widget-embed`)에 다운로드 버튼 없음.

## 할 일 (3개)
1. **러너에 파일생성 런타임 설치** — `backend/aimbase-agent/Dockerfile` 에 `python3 python3-pip` +
   `pip install python-pptx openpyxl reportlab python-docx` (+ 한글 폰트: pptx/pdf 한글 깨짐 방지 `fonts-nanum` 등).
   → 러너 이미지 재빌드 + `./deploy.sh agent` (러너만 재기동).
2. **CLI 산출물 폴더 → 다운로드 API** — working_directory(또는 그 하위 out/ 폴더)에 생성된 파일을 서빙하는
   GET 엔드포인트 신설. **테넌트 격리 필수**(TenantContext), 경로 탈출(../) 차단, Content-Disposition attachment.
   - run/session 단위로 산출물 폴더를 격리 (다른 테넌트/세션 파일 노출 금지).
3. **위젯: 산출물 감지 → 다운로드 버튼** — done 이벤트에 산출물 파일 메타(name/size/download_url) 실어 보내고,
   위젯이 "📎 제안서.pptx (240KB) [다운로드]" 칩으로 렌더. (CR-131 렌더러와 무관하게 독립 동작 가능)
   - BE done 페이로드 확장 필요 → chat SSE done 이벤트 스키마에 `artifacts[]` 추가.

## 결정 필요 (착수 세션에서)
- 산출물 폴더 수명: run 종료 시 삭제 vs TTL 보관(다운로드 유예). CLI worker 정리 훅(CR-114 계열)과 충돌 주의 — 파일 지우기 전 다운로드 가능해야 함.
- 프롬프트에 "파일은 ./out/ 에 생성하라" 규약을 심을지(system_prompt_override), CLI 자율에 맡기고 cwd 전체를 스캔할지.
