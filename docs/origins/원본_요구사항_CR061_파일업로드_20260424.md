## 핵심 결정사항

### 1. 파일 저장 방식 — (b) 사전 업로드 → attachment_id 참조
**대안**:
- (a) 메시지 전송 시 base64 인라인
- (b) 먼저 업로드 → `attachment_id` 반환 → 메시지에 ID 참조

**선택**: **(b)**
**이유**: 50MB PDF를 채팅 SSE 바디에 인라인하면 preflight/timeout/메모리 압박. 분리 업로드가 재전송(오류 시), 멀티파일, 프로그레스 바 표시 면에서도 유리.

### 2. PDF 처리 — Anthropic `document` 블록 우선 + 폴백
**Anthropic Claude**: 네이티브 `document` 블록(base64 PDF 직접 입력) 사용 — Vision+텍스트 모두 추출됨.
**OpenAI/Ollama/Bedrock**: PDF → 텍스트 추출(PyMuPDF, Python 사이드카) 후 텍스트 메시지로 인라인 폴백.
**판정 시점**: ChatController에서 라우팅 결정된 Adapter의 capability 플래그 확인.

### 3. 크기/개수 제한 (BIZ 신규)
| 항목 | 값 | 근거 |
|------|----|----|
| 이미지 단일 최대 | 10MB | Anthropic Vision 권장 상한 |
| PDF 단일 최대 | 32MB | Anthropic `document` 블록 상한(32MB) |
| 세션당 활성 첨부 | 10개 | 과도한 컨텍스트 주입 방지 |
| 첨부 TTL | 세션 TTL(24h)과 동일 | 세션 만료 시 함께 GC |

### 4. 위젯 UI 범위
- 입력창 좌측에 **클립 아이콘 버튼** — 클릭 시 파일 다이얼로그
- 입력창 **드래그앤드롭** 수용 — 파일 hover 시 점선 오버레이
- 첨부 미리보기 칩(썸네일 or 파일명) — 전송 전 제거 가능
- 이미지 프리뷰: 96x96 썸네일
- PDF 프리뷰: 파일명 + 페이지수("영수증.pdf · 3p") — 페이지수는 업로드 응답에서 제공

### 5. 보안/Scope
- 새 scope: **`chat:upload`** (위젯 토큰에 기본 포함 — `widget.allowed-scopes` 기본값에 추가)
- Origin 검증은 CR-058 CORS 화이트리스트 재사용
- 확장자+MIME 타입 이중 검증 (magic number 우선, Content-Type 보조)
- attachment 소유자(session_id) 검증 — 타 세션 ID 참조 시 403

## 엔드포인트

```
POST   /api/v1/chat/attachments
       multipart/form-data: file + session_id
       scope: chat:upload
       응답: { attachment_id, filename, media_type, size_bytes, pages?, preview_url? }

DELETE /api/v1/chat/attachments/{attachment_id}
       scope: chat:upload

POST   /api/v1/chat/completions        # 기존, 확장
       messages[].content[]에 { type: "image"|"document", attachment_id: "..." } 지원
```

## 데이터 모델

신규 테이블 `chat_attachments` (tenant DB, V58):
```sql
id              UUID PRIMARY KEY
session_id      VARCHAR NOT NULL
filename        VARCHAR NOT NULL
media_type      VARCHAR NOT NULL     -- image/png, application/pdf 등
size_bytes      BIGINT NOT NULL
storage_path    VARCHAR NOT NULL     -- StorageService.save() 반환값
pages           INTEGER              -- PDF만
checksum        VARCHAR(64)          -- SHA-256
created_at      TIMESTAMP NOT NULL
expires_at      TIMESTAMP NOT NULL   -- session TTL 동기화
```

인덱스: `(session_id)`, `(expires_at)` — 배치 GC용.

## 프로바이더별 Vision Capability

| 프로바이더 | 이미지 | PDF |
|-----------|-------|-----|
| Anthropic Claude 3.5+ | ✅ 네이티브 `image` 블록 | ✅ 네이티브 `document` 블록 |
| OpenAI GPT-4o | ✅ `image_url` | ❌ → 텍스트 추출 폴백 |
| Bedrock Claude | ✅ (Anthropic 경로) | ✅ (Anthropic 경로) |
| Ollama Llava | ✅ | ❌ → 텍스트 추출 폴백 |

**폴백 구현**: `PdfTextExtractor` 컴포넌트가 Python `parse_document` 도구 호출(기존 RAG 사이드카 재사용) → 텍스트를 메시지 앞에 "[첨부 PDF 텍스트]\n..." 형태로 주입.
