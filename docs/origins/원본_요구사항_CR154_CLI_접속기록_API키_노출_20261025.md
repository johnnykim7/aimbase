## 발견

## 원인 (CLI 2.1.197 바이너리)

- CLI 는 MCP 서버에 붙을 때마다 접속 설정을 기록 파일에 적는다. 이 기록을 끄는 설정은 없다(`initSinks` 가 MCP 기록 싱크를 늘 붙인다).
- 머리글은 이름이 `authorization` 으로 끝날 때만(대소문자 무시) `[REDACTED]` 로 가린다. 머리글 값의 환경변수 참조(`${VAR}`)나 headersHelper 로 넘겨도 펼친 값이 그대로 적힌다.
- 실행기는 서버 키를 `X-API-Key` 머리글로 넘긴다(ClaudeCliAdapterConfig).
